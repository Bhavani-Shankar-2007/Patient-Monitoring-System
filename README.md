# 🏥 Patient Monitoring System

An AI-assisted Patient Monitoring System built using **OpenAI Codex** and **GPT-5.6** to demonstrate a modern healthcare monitoring platform. The application helps healthcare professionals efficiently manage patient information, monitor health status, and maintain medical records through a clean and responsive web interface.

## 📖 Overview

The **Patient Monitoring System** is a full-stack healthcare application that streamlines patient management by providing a centralized dashboard for storing, updating, and monitoring patient information.

Developed with the assistance of **OpenAI Codex** and **GPT-5.6**, this project showcases modern software development practices, combining AI-assisted coding with human-led architecture, customization, testing, and deployment.

- 👤 Patient Registration

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Bhavani-Shankar-2007/Patient-Monitoring-System.git
```

### Navigate to the Project

```bash
cd Patient-Monitoring-System
```

### Install Dependencies

```bash
npm install
```

### Start the Application

```bash
npm start
```

For backend (if separate):

```bash
npm run server
```
